SharifNet

A lightweight Linux networking utility that makes connecting, disconnecting, and managing network access simple. Everyday connection controls become one clean command-line workflow, with configurable credentials and automatic reconnection.

  • One-command connect and disconnect
  • Configurable credentials
  • Automatic reconnection
  • Runs as a managed systemd service
  • Packaged for Debian / APT installs
  • Python codebase, easy to read and extend
Download latest release ↗ ★ Star & view on GitHub ↗
bash — sharifnet
# Install the Debian package
$ sudo apt install ./sharifnet_*.deb

# Check connection status
$ sharifnet status

# Connect to the network
$ sharifnet connect

# Configure automatic reconnect
$ sharifnet autoreconnect on
